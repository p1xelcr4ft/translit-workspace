# Translit Workspace

Быстрое и удобное десктопное приложение для транслитерации текста на базе **Electron**.

## ✨ Особенности

- **Поддержка 4 стандартов транслитерации**:
  - **SEO URL (ЧПУ)** — транслит для URL/ссылок с заменой пробелов на дефисы и приведением к нижнему регистру.
  - **Для ФИО (МИД)** — транслитерация по правилам Приказа МИД России № 4271 (для загранпаспортов и документов).
  - **По ГОСТу** — стандарт ГОСТ 7.79-2000 (Система Б).
  - **Обычный текст** — базовый стандарт ISO 9 для удобного чтения.
- **Глобальный хоткей (`Ctrl + Shift + T` / `Cmd + Shift + T`)**:
  - Быстрая транслитерация текста прямо из буфера обмена без открытия окна приложения.
  - Сопровождается ненавязчивым звуковым уведомлением системы.
- **Интеграция с системным треем**:
  - Быстрое переключение режимов из контекстного меню трея.
  - Сворачивание в трей при закрытии окна.
- **Темы и раскладки**:
  - Поддержка темной и светлой темы.
  - Переключение между боковой панелью и горизонтальными вкладками.

## 🚀 Установка и запуск

### Требования
- [Node.js](https://nodejs.org/) (версия 18+)

### Запуск в режиме разработки
```bash
npm install
npm start
```

### Сборка установщика (Windows NSIS)
```bash
npm run dist
```
